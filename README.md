# Donghyuck Yoon — Personal Website

A GitHub Pages personal/professional archive.

## Information architecture

- About
- Work · KMA
- Research
  - Research interests
  - Selected publications
  - Collapsible research background
- Archive

The site is intentionally weighted toward public-service work rather than research.

## Updating the site

Most recurring updates can be made in `content.js`.

Examples:
- Add a new KMA public-service project.
- Add an official KMA source URL.
- Add a new publication.
- Add a workshop or professional milestone.

## Public-service archive rule

Prefer:
- official KMA URLs
- official public PDFs / service pages
- public press releases
- public event pages or photos
- neutral wording such as “contributed to” or “role”

Avoid:
- internal reports
- non-public messenger screenshots
- unpublished internal analyses
- personal data of coworkers
- direct rehosting of official PDFs unless reuse conditions are confirmed
